# Security and private reports

Do not post credentials, private documents, wallet recovery material, or personal
data in public issues or pull requests. Use this repository's Security tab and
private vulnerability reporting when available. If it is unavailable, request a
private reporting channel without including the sensitive details.

This is a research prototype. Sample account balances and paper orders are not
real funds. It has no custody, transaction signing, or production trading capability.

Before submitting a patch, follow the privacy checks in [CONTRIBUTING.md](CONTRIBUTING.md).
