# Public release history

This repository retains the 100 recorded source-import commits from August 30 to
September 8, 2026. Their sequence, parent relationships, and recorded author and
committer timestamps are preserved. Commit hashes changed during sanitization.

Personal/project metadata was normalized and internal documents, editor bindings,
and unused portrait assets were excluded across history. Commits whose complete
contents were excluded remain as empty historical milestones. Historical import
snapshots are not independently runnable releases.

The source-import dates describe the available Git record. They do not establish
an earlier implementation timeline. No additional historical work or backdated
commits were invented. Paper-investing features that were uncommitted at release
preparation were added in a new commit using the actual preparation date.

Subsequent commits record publication safeguards, licensing, presentation, and
runtime configuration as those changes were made.
